## LLM and RAG document interpreter
This system is able to read documents provided and when asked a question it will generate answers from the document provided

This system can accept .txt and .pdf files

This system has customizable chunk sizes and overlap

This system has a delete button which removes all information about the documents

This system is able to display debug logs when toggled

This system can store knowledge from multiple files at a time

This system was made during a 2 week summer camp called circuit stream AI and Machine Learning with Python 2026
